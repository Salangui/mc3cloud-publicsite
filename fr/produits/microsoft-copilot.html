Microsoft Copilot et solutions IA

Microsoft 365 Copilot, agents IA, sécurité et développement : identifiez les solutions Microsoft adaptées aux usages de vos clients.

Choisir l’IA Microsoft selon les usages de vos clients

L’offre IA Microsoft ne se limite pas à un assistant conversationnel. Elle couvre le travail quotidien dans Microsoft 365, la création d’agents, les opérations de sécurité, le développement et les applications exploitant les données de l’entreprise.

Pour construire une proposition adaptée, il faut distinguer les licences utilisateur, les fonctionnalités intégrées aux applications et les services facturés à la consommation. Ce panorama présente les principales solutions ; il ne constitue pas une liste de licences interchangeables.

Productivité et travail quotidien

Microsoft 365 Copilot

L’assistant IA intégré à Word, Excel, PowerPoint, Outlook et Teams aide les utilisateurs à rédiger, analyser, synthétiser et préparer leur travail. Il exploite le contexte professionnel et les informations accessibles à l’utilisateur, notamment à travers Microsoft Graph et Work IQ.

Microsoft 365 Copilot Business

L’offre est destinée aux organisations jusqu’à 300 utilisateurs. Elle apporte les mêmes capacités Copilot, avec des modalités commerciales adaptées aux PME.

Microsoft 365 Copilot Chat

Un point d’entrée pour utiliser l’IA conversationnelle au travail, inclus sans supplément pour les utilisateurs Microsoft 365 éligibles.

Il faut distinguer le chat fondé sur le Web des usages exploitant les données partagées de l’entreprise : certains accès et agents sont facturés à la consommation en Copilot Credits.

Copilot Cowork

Pour déléguer un travail en plusieurs étapes plutôt que demander uniquement une réponse : préparer un dossier, créer des documents, organiser des réunions ou coordonner des communications.

Cowork s’appuie sur le contexte professionnel et demande une validation pour les actions sensibles. Ses usages consomment des Copilot Credits, en complément de la licence Microsoft 365 Copilot.

Copilot Code

Copilot Code permet de décrire en langage naturel une application, un tableau de bord ou une automatisation à construire.

Microsoft a annoncé son déploiement via le programme Frontier le 25 septembre 2026 ; son accès doit être vérifié dans l’environnement concerné. Ses usages consomment des Copilot Credits, en complément de la licence Microsoft 365 Copilot.

IA pour les équipes commerciales, le service client et la finance

Ces expériences métiers complètent Microsoft 365 Copilot en le connectant aux systèmes utilisés par les équipes :

  • Microsoft 365 Copilot for Sales : préparation des rendez-vous, consultation des opportunités et exploitation des informations commerciales issues des CRM pris en charge.
  • Microsoft 365 Copilot for Service : accès au contexte client et aux informations CRM dans les outils de travail, notamment Outlook et Teams.
  • Microsoft 365 Copilot for Finance : exploitation des données ERP dans Excel et Outlook, préparation des données et consultation d’informations financières.

Les fonctionnalités métiers existantes de ces trois expériences sont incluses dans Microsoft 365 Copilot depuis le 10 octobre 2025.

Créer et gouverner les agents IA

Microsoft Copilot Studio

Microsoft Copilot Studio permet de concevoir, tester et publier des agents connectés aux connaissances, aux applications et aux processus de l’entreprise.

La licence payante Microsoft Copilot Studio fournit une capacité au niveau du tenant : chaque pack comprend 25 000 Copilot Credits par mois.

Ces packs peuvent alimenter les agents Copilot Studio ainsi que les usages compatibles de Copilot Cowork et Copilot Code.

Le prépaiement permet de financer les usages pris en charge sans activer une facturation Azure PAYG pour cette consommation. Un relais PAYG peut être ajouté pour poursuivre les usages lorsque les crédits prépayés sont épuisés.

Cowork et Code nécessitent également une licence Microsoft 365 Copilot : les packs financent leur consommation, sans remplacer cette licence utilisateur.

Pour réaliser vos projets, découvrez notre service Agents métiers avec Microsoft Copilot Studio.

Microsoft Agent 365

La couche d’administration et de gouvernance des agents : inventaire, identités, contrôle des accès, observabilité, sécurité et gestion du cycle de vie.

Agent 365 complète les outils de création comme Copilot Studio ; il ne les remplace pas. Il est licencié par utilisateur et inclus dans Microsoft 365 E7.

IA pour les opérations de sécurité

Microsoft Security Copilot

L’IA destinée aux équipes de sécurité pour analyser les alertes, synthétiser les incidents et accompagner les investigations, notamment dans Microsoft Defender, Entra, Intune et Purview.

Les clients Microsoft 365 E5 et E7 éligibles bénéficient de 400 Security Compute Units par mois pour 1 000 licences utilisateur payantes.

Développement, modèles IA et données

Microsoft Foundry

La plateforme de développement d’applications et d’agents IA, précédemment appelée Azure AI Foundry, elle-même issue d’Azure AI Studio.

Elle réunit modèles, outils, agents, évaluation et contrôles de sécurité. Il s’agit d’une plateforme, pas d’une licence utilisateur unique.

Microsoft Fabric

La plateforme de données et d’analytique avec des expériences Copilot et des data agents. Leur consommation s’appuie sur les capacités Fabric, et non sur un simple supplément Microsoft 365 Copilot.

Une offre spécialisée pour la santé

Microsoft Dragon Copilot

L’offre IA clinique destinée aux professionnels de santé, avec des expériences adaptées aux médecins, aux radiologues et aux infirmiers. Elle vise notamment la documentation clinique, l’accès aux informations utiles et l’automatisation de tâches dans les parcours de soins.

Dragon Copilot constitue une offre verticale distincte de Microsoft 365 Copilot, avec ses propres intégrations aux systèmes de santé.

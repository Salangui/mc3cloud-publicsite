BitTitan MigrationWiz — Migration cloud, données et identités

Migrez les messageries, fichiers, données Teams et identités de vos clients avec BitTitan MigrationWiz, pour leurs projets Microsoft 365, Google Workspace et de consolidation de tenants.

Une plateforme pour les projets de migration de vos clients

BitTitan MigrationWiz permet aux MSP, intégrateurs et équipes IT de préparer et piloter des migrations de messageries, documents et données collaboratives depuis une interface cloud centralisée. Les scénarios couvrent Microsoft 365, Google Workspace et les environnements sources et destinations pris en charge par l’éditeur.

Les offres dédiées aux identités complètent ces migrations pour les projets impliquant Active Directory et Microsoft Entra ID. L’objectif : traiter les différents volets d’une transition, plutôt que limiter le projet au déplacement des boîtes aux lettres.

Six familles de besoins

  • Messageries et archives : déplacer les boîtes aux lettres et archives personnelles lors d’un changement de plateforme.
  • Fichiers et documents : migrer les données personnelles OneDrive ou Google Drive, ainsi que les bibliothèques partagées SharePoint et Google Shared Drives.
  • Collaboration Microsoft Teams : transférer les équipes, canaux et données associées ; distinguer ce périmètre des conversations privées incluses dans UMB.
  • Migration entre tenants : organiser le transfert des utilisateurs et des données entre environnements Microsoft 365.
  • Identités : migrer les objets d’annuaire dans les scénarios Active Directory et Microsoft Entra ID compatibles.
  • Fusions, acquisitions et cessions : combiner les migrations nécessaires pour consolider ou séparer les environnements Microsoft 365.

Choisir les offres adaptées au projet

Mailbox Migration

Pour une migration centrée sur la messagerie, entre plateformes compatibles. La licence couvre jusqu’à 50 GB par utilisateur.

User Migration Bundle — UMB

Pour migrer les données d’un utilisateur avec une seule licence : boîte aux lettres, archives personnelles, documents OneDrive ou Google Drive et conversations privées Microsoft Teams.

BitTitan annonce un volume de données illimité pour ce bundle. Les conversations privées comprennent l’historique, les titres, la mise en forme enrichie, les emojis, GIFs, stickers et messages longs.

Tenant Migration Bundle — TMB

Pour les migrations et consolidations Microsoft 365 entre tenants. Le bundle comprend UMB, auquel s’ajoute au choix Teams Migration ou Shared Documents 100 GB.

Le volume illimité d’UMB ne s’étend pas à ces extensions : Teams Migration et Shared Documents sont chacun plafonnés à 100 GB dans cette offre.

Teams Collaboration Migration

Pour migrer les équipes Microsoft Teams, les canaux et l’historique des conversations associé. La découverte des équipes et le suivi des opérations s’effectuent au niveau de chaque équipe.

La capacité annoncée est de 100 GB par équipe.

Shared Documents Migration

Pour déplacer des fichiers, dossiers, permissions, versions et métadonnées dans les scénarios compatibles.

Les licences existent en 50 GB ou 100 GB par bibliothèque documentaire, pour les migrations vers SharePoint Online, les bibliothèques Microsoft 365 Groups et entre Google Shared Drives.

Public Folder Migration

Pour moderniser les dossiers publics Exchange : messages, calendriers, contacts et autres contenus compatibles, vers des dossiers publics ou des boîtes partagées selon le scénario.

Le dimensionnement commercial s’effectue par tranches de 10 GB.

Active Directory / Entra ID Migration

Une licence distincte pour les migrations d’identités :

  • Active Directory local vers Active Directory local.
  • Microsoft Entra ID vers Microsoft Entra ID.
  • Active Directory local vers Microsoft Entra ID.
  • Microsoft Entra ID vers Active Directory local.

Pour les trois scénarios impliquant Entra ID, BitTitan indique une limite de ≤1000 utilisateurs et groupes de sécurité pour l’édition SMB. La licence est attribuée par utilisateur et valable 12 mois.

Les fonctionnalités de reprise des objets, structures d’unités organisationnelles, historiques SID et mots de passe dépendent du scénario ; celles-ci sont notamment documentées pour AD local vers AD local.

Piloter les migrations depuis une interface centralisée

MigrationWiz permet de définir les sources et destinations, importer les utilisateurs et éléments à migrer, vérifier les accès et lancer les passes de migration.

Les options avancées comprennent le filtrage par dates, les correspondances de dossiers et de destinataires, ainsi que le choix de centres de données régionaux.

Les projets peuvent être partagés entre les agents d’un même Workgroup. Des journaux d’actions et des fonctions d’audit contribuent au suivi des opérations. BitTitan documente également le chiffrement des données en transit et au repos.

Ne pas confondre migration des données et migration des postes

Pour les postes Windows, BitTitan propose notamment PowerSyncPro Migration Agent : migration entre AD, Entra ID et groupes de travail, conservation du profil utilisateur et reconfiguration des applications Microsoft 365.

Ce complément dispose de ses propres prérequis : un serveur Windows pour héberger le service PowerSyncPro et une licence par appareil, valable 12 mois. Il ne doit pas être considéré comme une fonctionnalité automatiquement incluse dans UMB ou TMB.

Microsoft Azure

Le cloud public de Microsoft : calcul, stockage, réseau, données et IA, facturés à la consommation.

Azure est la plateforme de cloud public de Microsoft : machines virtuelles, stockage, réseau, bases de données, services d’IA. La consommation est facturée au revendeur, puis à son client.

Ce que vous pouvez proposer

  • Migration de serveurs et de machines virtuelles vers Azure.
  • Sauvegarde et reprise d’activité avec Azure Backup et Azure Site Recovery.
  • Nouveaux projets applicatifs et données sur Azure.

Avec MC3 Cloud

  • Azure via le programme CSP, avec suivi de la consommation.
  • Des packs de services pour démarrer : migration vers Azure et continuité d’activité.
  • Un accompagnement avant-vente spécialisé Azure.

Bon à savoir

Microsoft applique des règles de vente différentes selon les territoires : certaines offres Azure ne sont pas disponibles partout. Contactez-nous pour vérifier ce qui s’applique à votre pays.

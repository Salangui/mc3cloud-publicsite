Microsoft Work IQ : comprendre son fonctionnement, ses accès et sa tarification

Work IQ est la couche d’intelligence qui alimente Microsoft 365 Copilot. Découvrez ses composants, les différentes façons dont les agents peuvent y accéder et les cas dans lesquels des Credits peuvent être consommés.

Microsoft 365Par Équipe MC3 Cloud28 octobre 2026

Vous créez deux agents capables de chercher dans les données de votre entreprise. Ils utilisent la même intelligence, mais pas forcément le même mode de facturation.

C’est tout l’enjeu de Work IQ : ce n’est pas seulement ce que fait l’agent qui compte, mais aussi l’endroit où vous le construisez et la façon dont il accède aux données.

Work IQ, c’est quoi ?

Work IQ est la couche qui permet à Copilot et aux agents de comprendre les informations de l’entreprise dans Microsoft 365.

Concrètement, Work IQ peut :

  • retrouver une information par son sens, même sans utiliser les mots exacts ;
  • respecter les droits d’accès de chaque utilisateur ;
  • rassembler plusieurs éléments pour construire une réponse utile ;
  • donner à un agent un accès encadré aux données de l’organisation.

Work IQ ne donne donc pas accès à tout. L’agent ne voit que ce que l’utilisateur qui l’exécute est autorisé à consulter.

La différence se joue au moment de créer l’agent

Prenons un exemple simple : vous voulez créer un agent capable de retrouver des informations dans Microsoft 365.

Avec Agent Builder, l’agent fonctionne directement dans Microsoft 365 Copilot. L’accès à Work IQ est natif et couvert par la licence Microsoft 365 Copilot.

Avec un agent Copilot Studio standard, vous choisissez à l’avance son fonctionnement. L’agent accède à Outlook, Teams, SharePoint ou OneDrive à travers les connecteurs et outils prévus pour chaque service. Il n’appelle pas automatiquement Work IQ.

Avec un agent autonome ou une application développée sur mesure, Work IQ peut devenir un outil que l’agent appelle lorsqu’il en a besoin. C’est plus souple, mais cette consommation peut être facturée séparément en Copilot Credits.

Quand est-ce que vous payez ?

Créer un agent ne déclenche pas automatiquement une facturation Work IQ.

Le compteur Work IQ entre en jeu lorsque l’agent utilise directement l’API Work IQ, ou lorsqu’un outil Work IQ a été ajouté à son environnement.

Le coût devient donc plus difficile à prévoir pour un agent autonome capable de lancer de nombreuses recherches sans intervention humaine.

Le piège à éviter

Copilot Studio et Work IQ utilisent des compteurs différents.

Vous pouvez limiter les crédits de l’agent dans Power Platform sans avoir limité sa consommation Work IQ. Les deux budgets doivent donc être suivis séparément.

Avant la mise en production, vérifiez :

  • comment l’agent accède aux données Microsoft 365 ;
  • si l’API Work IQ est réellement nécessaire ;
  • où sont définies les limites de dépenses ;
  • si les droits SharePoint, Teams et OneDrive sont correctement maîtrisés.

Quel choix faire ?

Le bon choix dépend surtout du besoin :

  • Agent Builder pour un assistant simple intégré à Microsoft 365 Copilot ;
  • Copilot Studio standard pour un processus défini et contrôlé étape par étape ;
  • Work IQ via API pour un agent plus autonome, capable de décider lui-même de ses recherches.

Plus l’agent gagne en autonomie, plus le suivi des coûts et des accès devient important.

À retenir

Work IQ apporte la même intelligence à plusieurs types d’agents. Mais le chemin utilisé pour y accéder change les capacités, les contrôles et la facture.

Avant de choisir une architecture, posez trois questions simples : où l’agent sera-t-il construit, comment accédera-t-il aux données et quel compteur sera utilisé ?

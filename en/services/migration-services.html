Migration services

Packs to migrate to Microsoft 365 and Azure, with proven tools and a team that handles the delivery.

You sell the project, our teams handle the delivery. Three packs cover the most common migrations.

Microsoft 365: starter

Setup and migration of a new Microsoft 365 tenant: DNS and Microsoft Entra ID configuration, security baseline, mailbox migration.

Microsoft 365: file migration

Moving from another cloud service to Microsoft 365: email, OneDrive and SharePoint library setup.

Azure: basic migration

Migration of on-premises servers or virtual machines to Azure IaaS: discovery and assessment, planning and cost estimate, infrastructure deployment (compute, storage, networking), execution, testing and final commit, Azure Backup and Defender for Cloud configuration.

Migration tools such as BitTitan MigrationWiz are part of the toolbox.

What it covers

  • Microsoft 365 starter pack: tenant, DNS, Entra ID, security baseline, mailbox migration
  • File migration pack: email, OneDrive, SharePoint libraries
  • Azure basic migration pack: assessment, planning, deployment, migration and validation

Microsoft Copilot and AI solutions

Microsoft 365 Copilot, AI agents, security and development: identify the Microsoft solutions that match your customers’ needs.

Choose Microsoft AI around your customers’ needs

Microsoft’s AI portfolio extends beyond conversational assistants. It covers everyday work in Microsoft 365, agent creation, security operations, development and applications that use business data.

Building the right proposal means distinguishing user licences, capabilities built into applications and consumption-based services. This overview introduces the main solutions; it is not a list of interchangeable licences.

Productivity and everyday work

Microsoft 365 Copilot

The AI assistant built into Word, Excel, PowerPoint, Outlook and Teams helps users draft, analyse, summarise and prepare their work. It draws on business context and information the user can access, including through Microsoft Graph and Work IQ.

Microsoft 365 Copilot Business

The offer is for organisations with up to 300 users. It provides the same Copilot capabilities, with commercial options designed for small and medium-sized businesses.

Microsoft 365 Copilot Chat

An entry point for conversational AI at work, included at no additional charge for eligible Microsoft 365 users.

Web-grounded chat must be distinguished from scenarios that use shared business data: some access and agent usage is metered in Copilot Credits.

Copilot Cowork

Delegate multi-step work rather than simply asking for an answer: prepare a briefing, create documents, organise meetings or coordinate communications.

Cowork uses business context and requests approval for sensitive actions. Its usage consumes Copilot Credits in addition to the Microsoft 365 Copilot licence.

Copilot Code

Copilot Code lets users describe an application, dashboard or automation in natural language and have it built.

Microsoft announced its rollout through the Frontier programme on 25 September 2026; access must be checked in the relevant environment. Its usage consumes Copilot Credits in addition to the Microsoft 365 Copilot licence.

AI for sales, customer service and finance teams

These role-based experiences extend Microsoft 365 Copilot by connecting it to the systems teams use:

  • Microsoft 365 Copilot for Sales: prepare for meetings, review opportunities and use sales information from supported CRM systems.
  • Microsoft 365 Copilot for Service: access customer context and CRM information within work tools, including Outlook and Teams.
  • Microsoft 365 Copilot for Finance: work with ERP data in Excel and Outlook, prepare data and review financial information.

The existing role-based capabilities of these three experiences have been included in Microsoft 365 Copilot since 10 October 2025.

Build and govern AI agents

Microsoft Copilot Studio

Microsoft Copilot Studio lets teams design, test and publish agents connected to business knowledge, applications and processes.

The paid Microsoft Copilot Studio licence provides tenant-level capacity: each pack includes 25,000 Copilot Credits per month.

These packs can fund Copilot Studio agents as well as supported Copilot Cowork and Copilot Code usage.

Prepaid capacity can fund supported usage without enabling Azure pay-as-you-go billing for that consumption. Pay-as-you-go can be added as a fallback to maintain access when prepaid credits run out.

Cowork and Code also require a Microsoft 365 Copilot licence: capacity packs fund consumption without replacing that user licence.

To deliver your projects, explore our Business agents with Microsoft Copilot Studio service.

Microsoft Agent 365

The administration and governance layer for agents: inventory, identities, access controls, observability, security and lifecycle management.

Agent 365 complements agent-building tools such as Copilot Studio; it does not replace them. It is licensed per user and included in Microsoft 365 E7.

AI for security operations

Microsoft Security Copilot

AI for security teams to analyse alerts, summarise incidents and support investigations, including within Microsoft Defender, Entra, Intune and Purview.

Eligible Microsoft 365 E5 and E7 customers receive 400 Security Compute Units per month for every 1,000 paid user licences.

Development, AI models and data

Microsoft Foundry

The platform for developing AI applications and agents, previously known as Azure AI Foundry, which evolved from Azure AI Studio.

It brings together models, tools, agents, evaluation and security controls. It is a platform, not a single user licence.

Microsoft Fabric

The data and analytics platform with Copilot experiences and data agents. Their consumption relies on Fabric capacity rather than a simple Microsoft 365 Copilot add-on.

A specialised offer for healthcare

Microsoft Dragon Copilot

The clinical AI offer for healthcare professionals, with experiences tailored to physicians, radiologists and nurses. It supports clinical documentation, access to relevant information and task automation within care workflows.

Dragon Copilot is a vertical offering distinct from Microsoft 365 Copilot, with its own integrations into healthcare systems.

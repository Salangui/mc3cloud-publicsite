BitTitan MigrationWiz — Cloud, Data and Identity Migration

Migrate your customers’ email, files, Teams data and identities with BitTitan MigrationWiz for Microsoft 365, Google Workspace and tenant consolidation projects.

A platform for your customers’ migration projects

BitTitan MigrationWiz enables MSPs, system integrators and IT teams to prepare and manage email, document and collaboration data migrations through a centralised cloud interface. Supported scenarios cover Microsoft 365, Google Workspace and the source and destination environments supported by the vendor.

Dedicated identity offerings complement these migrations for projects involving Active Directory and Microsoft Entra ID. This helps address the different parts of a transition rather than treating the project as a mailbox move alone.

Six migration needs

  • Email and archives: move mailboxes and personal archives when changing platforms.
  • Files and documents: migrate personal OneDrive or Google Drive data, along with shared SharePoint libraries and Google Shared Drives.
  • Microsoft Teams collaboration: transfer teams, channels and associated data; distinguish this scope from the private chats included in UMB.
  • Tenant-to-tenant migration: organise the transfer of users and data between Microsoft 365 environments.
  • Identities: migrate directory objects across supported Active Directory and Microsoft Entra ID scenarios.
  • Mergers, acquisitions and divestitures: combine the migrations needed to consolidate or separate Microsoft 365 environments.

Choose the right offerings for the project

Mailbox Migration

For email-focused migrations between supported platforms. The licence covers up to 50 GB per user.

User Migration Bundle — UMB

Migrate a user’s data with a single licence covering the mailbox, personal archives, OneDrive or Google Drive documents and Microsoft Teams private chats.

BitTitan specifies unlimited data for this bundle. Private chat migration includes chat history, titles, rich content formatting, emojis, GIFs, stickers and long messages.

Tenant Migration Bundle — TMB

For Microsoft 365 tenant-to-tenant migrations and consolidation. The bundle includes UMB, plus a choice of Teams Migration or Shared Documents 100 GB.

UMB’s unlimited data allowance does not extend to these options: Teams Migration and Shared Documents are each capped at 100 GB within this offering.

Teams Collaboration Migration

Migrate Microsoft Teams teams, channels and associated conversation history. Team discovery and migration monitoring are managed at the individual team level.

The stated capacity is 100 GB per team.

Shared Documents Migration

Move files, folders, permissions, versions and metadata in supported scenarios.

Licences are available with 50 GB or 100 GB per document library, for migrations to SharePoint Online, Microsoft 365 Groups document libraries and between Google Shared Drives.

Public Folder Migration

Modernise Exchange Public Folders by moving email, calendars, contacts and other supported content to public folders or shared mailboxes, depending on the scenario.

Licensing is sized in 10 GB increments.

Active Directory / Entra ID Migration

A separate licence for identity migrations:

  • On-premises Active Directory to on-premises Active Directory.
  • Microsoft Entra ID to Microsoft Entra ID.
  • On-premises Active Directory to Microsoft Entra ID.
  • Microsoft Entra ID to on-premises Active Directory.

For the three scenarios involving Entra ID, BitTitan specifies a limit of ≤1000 users and security groups for the SMB edition. The licence is assigned per user and is valid for 12 months.

Support for migrating objects, organisational unit structures, SID History and passwords depends on the scenario; these capabilities are specifically documented for on-premises AD-to-AD migrations.

Manage migrations through a centralised interface

MigrationWiz lets you define sources and destinations, import users and items, verify access and launch migration passes.

Advanced options include date filtering, folder and recipient mapping, and regional data centre selection.

Projects can be shared among agents in the same Workgroup. Action logs and audit capabilities help teams track operations. BitTitan also documents encryption for data in transit and at rest.

Distinguish data migration from workstation migration

For Windows workstations, BitTitan offers PowerSyncPro Migration Agent, supporting moves between AD, Entra ID and workgroups, retention of Windows user profiles and reconfiguration of Microsoft 365 applications.

This complementary product has its own requirements: one Windows server to host the PowerSyncPro service and a licence per device, valid for 12 months. It should not be treated as a feature automatically included in UMB or TMB.
